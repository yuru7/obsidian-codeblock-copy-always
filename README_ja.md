# Codeblock Copy Always

[English](README.md) | [日本語](README_ja.md)

[Obsidian](https://obsidian.md) のライブプレビューで、フェンス付きコードブロックを編集しているあいだもコピーボタンを表示し続けるプラグインです。

## なぜ必要か

ライブプレビューでは、カーソルがコードブロックの外にあるとき、言語名とコピー操作がコードブロック上に表示されます。編集のためにブロック内をクリックすると、その操作は消えます。

このプラグインはそのすき間を埋めます。フェンス付きコードブロックを編集しているあいだ、コピーアイコンがブロック右上に残ります。

## 使い方

1. ノートを **ライブプレビュー** で開きます。
2. フェンス付きコードブロック（`` ``` `` または `~~~`）の中にカーソルを置きます。
3. ブロック右上のコピーアイコンをクリックします。

コピーされるのはコード本体だけで、フェンス行は含まれません。コピーに成功すると、アイコンが短時間チェックマークに変わります。

カーソルがブロックの外に出るか、エディターからフォーカスが外れると、プラグインはボタンを隠し、Obsidian 標準のコピー操作が再び表示されるようにします。

設定項目はありません。プラグインを有効にすれば使えます。

## インストール

### コミュニティプラグインから

コミュニティプラグインから **Code Block Copy Always** を検索してインストールしてください。

## 動作条件

- Obsidian 1.8.0 以降
- デスクトップ（Windows、macOS、Linux）

## 制限

- ライブプレビュー専用です。閲覧ビューにはもともとコピーボタンがあり、ソースモードは変更しません。
- フェンス付きコードブロックのみ対象です。インデントされたコードブロックには対応しません。
- デスクトップ専用です。モバイルでは動作しません。
